# Machine Problems: (All MP requires a loop)

<ul>
<li> Create a program that will display the first 10 natural numbers </li> 
<li> Create a program that will display the first 20 odd natural numbers </li>
<li> Create a program that will display the average of the generated numbers. User must enter the quantity of numbers to be generated </li>
<li> Create a program that display the cube of an integer up to the inputted number </li>
<li> Create a program that will display the fibonacci sequence. User will input how many numbers will be generated </li>
</ul>
