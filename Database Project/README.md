# DEMPA: Your Partner in Global Electronics
This is a project that me and my groupmates made for a major subject.
It relates to helping a company or LGUs for their problem and we offer a system as a solution to those problems.

https://asl-topaz.vercel.app

It's a filtering system of the following:
<ul>
  <li> Active & Inactive accounts </li>
  <li> Accounts with multiple emails </li>
  <li> By country </li>
</ul>
